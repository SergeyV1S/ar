# Метрика

Веб-планировщик мебели на React и Vite. Пространственные измерения и просмотр используют WebXR. Проект и расчёты хранятся в браузере.

## Запуск

```sh
docker compose up --build -d
```

Откройте [http://localhost:4178](http://localhost:4178). Для доступа с телефона установите `METRIKA_BIND` в IPv4-адрес нужного сетевого интерфейса компьютера перед запуском Compose. Команды для разработки запускаются из `front/`: `yarn install --frozen-lockfile`, `yarn dev`, `yarn typecheck`, `yarn lint`, `yarn test` и `yarn build`.

## Подбор мебели

В корневом `.env` задайте `GIGACHAT_AUTH_KEY` для GigaChat 3 Ultra и `DIVAN_CATALOG_ENABLED=1` для Divan.ru. Ultra доступна в режиме Freemium для физлиц. Бэкенд использует сертификаты Минцифры только для HTTPS-запросов к GigaChat.

Запуск с Авито

```sh
docker compose -f compose.yaml -f compose.avito.yaml up --build -d
```

Поиск выполняется через [Avito MCP](https://github.com/ermizin/avito-mcp). Если Авито остановит поиск, откройте [браузер MCP](http://localhost:6080/vnc.html?autoconnect=1), пройдите проверку и повторите поиск в каталоге. Профиль браузера сохраняется в томе Docker. Интерфейс браузера доступен на loopback, HTTP MCP доступен в сети Compose.

После обмера и расстановки своей мебели откройте шаг «Подбор мебели». GigaChat разберёт текст или расшифровку записи с учётом комнаты и мебели. Выберите город и откройте карточку нужной позиции, чтобы сравнить Divan.ru и Авито. Подтвердите замену, если хотите убрать старый предмет. В шаге «Расстановка» можно выбрать вариант и передвинуть любые предметы. В смете доступны CSV, отдельный план PNG и печать плана со сметой в PDF.

## Голосовой ввод

Для Docker Compose задайте `GROQ_API_KEY` в окружении или в файле `.env` в корне проекта. Для разработки без Docker задайте ключ в окружении или в `back/.env`, затем запустите `yarn install --frozen-lockfile` и `yarn dev` из `back/`, а `yarn dev` для интерфейса запустите отдельно из `front/`. Бэкенд слушает порт `3000`, Vite проксирует запросы к нему. Проверки бэкенда запускаются из `back/` командами `yarn test`, `yarn typecheck` и `yarn build`.

Если для доступа к Groq нужен исходящий прокси, задайте `GROQ_PROXY_URL` там же, где задан ключ. Бэкенд использует этот прокси только для запросов к Groq. Поддерживаются HTTP, HTTPS и SOCKS5.

Во время записи приложение отправляет в Groq аудио по 3 секунды и показывает черновик. При остановке или по истечении 60 секунд приложение отправляет всю запись для уточнения текста. При сбое уже показанный текст остаётся доступным для правки. В шаге «Подбор мебели» нажмите «Проанализировать пожелания» и проверьте список покупок перед сохранением.

Одна 60-секундная запись отправляет до 19 чанков и один итоговый запрос. Квота Groq общая для организации. Без ключа или сети поле можно заполнить вручную. Микрофон доступен на `localhost` и через HTTPS. Для проверки на телефоне откройте сборку через доверенный HTTPS-прокси в закрытом тестовом окружении.

## AR

Откройте сайт по HTTPS в совместимом Chrome на Android с ARCore. В режиме обмера последовательно отметьте углы по периметру: точка рядом с первым углом замыкает контур. Привязка к осям, подсказка длины стены, сетка пола и подсветка найденной поверхности помогают держать нужную точку. Затем отметьте края проёмов и розетки. В режиме просмотра отметьте начало плана и вторую точку вдоль верхней стены вправо, поверните модель кнопкой при необходимости.

В AR известная мебель отображается моделью из `front/public/models/furniture/` с габаритами предмета. Пока модель загружается или для предмета без модели, виден прямоугольный блок по его размерам. Предмет вне списка распознавания можно выделить и измерить вручную через AR-камеру.

Модели FurniMesh адаптированы для мобильной загрузки. `table.glb` — модель «Тамада, Стол 1800» © RePanel. [Страница изделия RePanel](https://re-panel.ru/catalog/tamada-stol-1800)

## Фото и каталог

Распознавание на фото и в режиме AR выполняется в браузере моделью OWLv2. Модель подгружается при первом распознавании. Она предлагает тип предмета, а габариты требуют проверки. Результат AR-обмера частично видимого предмета помечается как приблизительный.

Каталог показывает опубликованные продавцами фотографии. В режиме «Новая покупка» подбор Divan.ru запускается с плана или со страницы каталога. Выберите город и подтвердите условия вручную или после голосового ввода. Порядок товаров берётся из сортировки «Самые популярные», а план проверяет размещение всех экземпляров и остаток заданного бюджета. Цены и наличие берутся из регионального списка с кэшем до 30 минут. Ссылка в карточке ведёт на товар. Итоговую цену и условия доставки проверьте у продавца после выбора города.

Подбор использует фактические характеристики и ссылки из публичных страниц Divan.ru и Авито. Предложения аренды исключаются из результатов. Недостающие размеры можно ввести после уточнения у продавца. Реквизиты служебной закупки можно внести вручную.

Модель мебели основана на [Google OWLv2 Base Patch16 Ensemble](https://huggingface.co/google/owlv2-base-patch16-ensemble), лицензия Apache-2.0. Для браузера в графе закреплён словарь мебели, добавлены входы с разным соотношением сторон и объединены операции внимания. Исходные `onnx/model_quantized.onnx` и `tokenizer.json` взяты из [экспорта Xenova](https://huggingface.co/Xenova/owlv2-base-patch16-ensemble/tree/3e255bc9bf304b3358a8c1945c0a9514eefe7f10). Чтобы обновить модель, установите Python-пакеты `numpy`, `onnx`, `onnxruntime`, `tokenizers` и запустите команду из корня проекта.

```sh
python3 front/scripts/export-furniture-model.py model_quantized.onnx tokenizer.json front/public/furniture-model/owlv2-furniture-v1.onnx
```

Для публикации изменённых весов используйте новое имя файла в `detector.worker.ts`, чтобы браузер загрузил обновлённую модель.
