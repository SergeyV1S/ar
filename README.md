# Метрика

Веб-планировщик мебели на React и Vite. Пространственные измерения и просмотр используют WebXR. Проект и расчёты хранятся в браузере.

## Запуск

```sh
docker compose up --build -d
```

Откройте [http://localhost:4178](http://localhost:4178). Для доступа с телефона установите `METRIKA_BIND` в IPv4-адрес нужного сетевого интерфейса компьютера перед запуском Compose. Для разработки доступны `npm ci`, `npm run dev`, `npm test` и `npm run build`.

## AR

Откройте сайт по HTTPS в совместимом Chrome на Android с ARCore. В режиме обмера последовательно отметьте углы по периметру, затем края проёмов и розетки. В режиме просмотра отметьте начало плана и вторую точку вдоль верхней стены вправо. Привязка действует в пределах текущей сессии AR. Модели мебели упрощённые и имеют заданные габариты.

## Фото и каталог

Распознавание по фото выполняется в браузере моделью TensorFlow COCO-SSD Lite MobileNet V2. Оно предлагает тип предмета и оставляет размеры для ручной проверки. Иллюстрации карточек сделаны встроенным ImageGen по заданию на журнальный стол, дубовую тумбу и светлый пуф. Встроенный каталог содержит примеры реальных розничных предложений. Объявления и КП добавляются по ссылкам, а актуальные цены и наличие проверяются у продавца.

Модель и API описаны в [проекте TensorFlow.js Models](https://github.com/tensorflow/tfjs-models/tree/master/coco-ssd). Исходники проекта TensorFlow.js Models распространяются по лицензии Apache-2.0.
