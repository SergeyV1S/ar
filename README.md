# Метрика

Веб-планировщик мебели на React и Vite. Пространственные измерения и просмотр используют WebXR. Проект и расчёты хранятся в браузере.

## Запуск

```sh
docker compose up --build -d
```

Откройте [http://localhost:4178](http://localhost:4178). Для доступа с телефона установите `METRIKA_BIND` в IPv4-адрес нужного сетевого интерфейса компьютера перед запуском Compose. Команды для разработки запускаются из `front/`: `yarn install --frozen-lockfile`, `yarn dev`, `yarn typecheck`, `yarn lint`, `yarn test` и `yarn build`.

## Голосовой ввод

Для Docker Compose задайте `GROQ_API_KEY` в окружении или в файле `.env` в корне проекта. Для разработки без Docker задайте ключ в окружении или в `back/.env`, затем запустите `yarn install --frozen-lockfile` и `yarn dev` из `back/`, а `yarn dev` для интерфейса запустите отдельно из `front/`. Бэкенд слушает порт `3000`, Vite проксирует запросы к нему. Проверки бэкенда запускаются из `back/` командами `yarn test`, `yarn typecheck` и `yarn build`.

Если для доступа к Groq нужен исходящий прокси, задайте `GROQ_PROXY_URL` там же, где задан ключ. Бэкенд использует этот прокси только для запросов к Groq. Поддерживаются HTTP, HTTPS и SOCKS5.

При остановке записи или по истечении 60 секунд аудио отправляется в Groq. Распознанный текст появляется в поле «Размеры и пожелания». Без ключа или сети можно заполнить поле вручную. Микрофон доступен на `localhost` и через HTTPS. Для проверки на телефоне откройте сборку через доверенный HTTPS-прокси в закрытом тестовом окружении.

## AR

Откройте сайт по HTTPS в совместимом Chrome на Android с ARCore. В режиме обмера последовательно отметьте углы по периметру, затем края проёмов и розетки. В режиме просмотра отметьте начало плана и вторую точку вдоль верхней стены вправо. Привязка действует в пределах текущей сессии AR. Модели мебели упрощённые и имеют заданные габариты.

## Фото и каталог

Распознавание по фото выполняется в браузере моделью TensorFlow COCO-SSD Lite MobileNet V2. Оно предлагает тип предмета и оставляет размеры для ручной проверки. Иллюстрации карточек сделаны встроенным ImageGen по заданию на журнальный стол, дубовую тумбу и светлый пуф. Каталог использует локальные демонстрационные данные для Hoff, б/у и служебной закупки. Цена и наличие в карточках тестовые. В служебном наборе есть пример КП с условными реквизитами поставщика.

Модель и API описаны в [проекте TensorFlow.js Models](https://github.com/tensorflow/tfjs-models/tree/master/coco-ssd). Исходники проекта TensorFlow.js Models распространяются по лицензии Apache-2.0.
