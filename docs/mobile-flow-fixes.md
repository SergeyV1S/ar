# Исправления мобильного сценария

Данные комнаты, покупок и размеров должны исходить от пользователя, измерений или опубликованных карточек. AR-шаблоны масштабируются по габаритам предмета.

- [x] 1. Пустой AR-обмер. Новый проект открывается без примерной мебели. Старые автоподставленные диван и кресло не переносятся в новый AR-обмер. Пользовательские предметы остаются в проекте. Проверено 40 тестами фронтенда.
- [x] 2. Бюджет. Новый проект открывается без указанного бюджета. Анализ берёт цены и материалы из запроса. Смета и каталог работают без лимита, пока пользователь его не задаст. Проверены пустой бюджет, импорт старого значения и ответ ИИ с выдуманными ограничениями.
- [x] 3. Каталог и смета. Применить оформление Плана к заголовкам, навигации, панелям, формам и действиям. Проверено в Chromium при ширине 390 и 1280 пикселей.
- [x] 4. Выдача с фото. Передать опубликованные фото из Divan.ru и Avito MCP, убрать аренду и исправить ширину карточек. Проверены реальные фото обоих источников в Chromium на 390 пикселях и фильтр аренды. Демонстрационная выдача удалена.
- [x] 5. Термины и размеры. Показывать «Длина» вместо «Глубина». Поддержать оба названия при чтении объявлений и сохранить существующую ось размера. Проверены тесты парсера, голосового ввода и планировщика.
- [x] 6. Мобильный сценарий. Кнопки обмера стоят над формой, условия подбора сворачиваются, смета компактнее, а при выборе варианта план попадает в область видимости. Проверены новый проект, ввод размеров и страницы на ширине 390 пикселей.
