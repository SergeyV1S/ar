# Назначение приоритета алерта

**ФТ-01.** Система должна назначать приоритет алерту по серьёзности, типу устройства и числу затронутых клиентов согласно таблице.

| Серьёзность | Тип устройства | Затронутые клиенты | Ожидаемый приоритет |
|---|---|---:|---|
| CRITICAL | Core Router | Любое число | P1 |
| CRITICAL | Access Switch | > 50 | P1 |
| CRITICAL | Access Switch | ≤ 50 | P2 |
| MAJOR | Любой | > 100 | P2 |
| MAJOR | Любой | ≤ 100 | P3 |
| MINOR | Любой | Любое число | P4 |
| WARNING | Любой | Любое число | P5 |

Соседние условия для CRITICAL-алерта на Core Router объединены. И до 100 клиентов включительно, и свыше 100 результатом служит P1. Для Access Switch проверь 50 и 51 клиента. Для MAJOR проверь 100 и 101. Уточни поведение для других типов оборудования с CRITICAL и для отсутствующих уровней серьёзности, если эти входы возможны.

Время обработки образует отдельное обязательство. Для P1 задано до 5 минут, для P2 — до 15 минут, для P3 — до 60 минут, для P4 — до 4 часов, для P5 — в рабочее время. Для проверки уточни начало отсчёта и определение рабочего времени.
