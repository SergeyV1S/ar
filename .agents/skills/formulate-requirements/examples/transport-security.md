# Минимальная версия протокола при передаче данных

| ID | Требование | Критерий приёмки |
|---|---|---|
| НФТ-01 | Для соединений с API и UI сервиса NMS должен использоваться TLS версии 1.2 или выше. | Проверка настроек и подключений для охваченных API и UI подтверждает TLS 1.2 или выше. Успешное соединение без TLS или с версией ниже 1.2 нарушает ограничение. |

Проверь, что версия и область действия явно заданы проектом. Шифрование хранимых данных и срок хранения записей аудита проверяются как самостоятельные свойства.
