# Сопоставление серьёзности трапа и алерта

**ФТ-01.** При обработке SNMP-трапа система должна присваивать создаваемому алерту серьёзность по значению `severity` из таблицы.

Для каждой строки подай трап с указанной серьёзностью. Система создаёт алерт с соответствующей серьёзностью.

| Серьёзность трапа | Серьёзность алерта |
|---|---|
| emergencies | CRITICAL |
| alerts | CRITICAL |
| critical | MAJOR |
| errors | MAJOR |
| warnings | MINOR |
| notifications | WARNING |
| informational | INFO |

Проверь регистр и точное соответствие значений. Если возможны отсутствующие или неизвестные значения, уточни ожидаемую реакцию системы.
