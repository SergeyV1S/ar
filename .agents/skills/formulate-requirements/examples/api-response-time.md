# Время ответа API при заданной нагрузке

| ID | Требование | Критерий приёмки |
|---|---|---|
| НФТ-01 | Для запроса списка алертов p95 времени ответа API должен быть не более 200 мс при 500 запросах в секунду и 10 000 устройствах. | При нагрузочном замере в тестовой среде с 10 000 устройствами и нагрузкой 500 запросов в секунду p95 задержки запроса списка алертов составляет не более 200 мс. |

Проверь совпадение операции, нагрузки, объёма данных, перцентиля и порога с источником. При p95 ровно 200 мс порог соблюдён. Если окно замера или профиль запросов влияют на воспроизводимость, уточни их.

Для запроса деталей алерта задан другой порог, p95 не более 100 мс при 500 запросах в секунду. Условие о 10 000 устройствах указано для списка алертов. Для другого учебного запроса, списка устройств, задан p95 не более 500 мс при 100 запросах в секунду. Записывай каждый порог вместе с его операцией и условиями.
