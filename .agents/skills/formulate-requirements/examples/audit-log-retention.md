# Минимальный срок хранения журналов аудита

| ID | Требование | Критерий приёмки |
|---|---|---|
| НФТ-01 | Сервис мониторинга NMS должен хранить журналы аудита не менее 3 лет. | По установленному правилу отсчёта журналы остаются доступными в течение как минимум 3 лет. Удаление журнала до истечения этого срока нарушает требование. |

Уточни состав журналов, момент начала отсчёта и документ, устанавливающий обязательство для проекта. В учебном наборе одновременно встречаются минимум 1 год для журнала действий пользователей и минимум 3 года для журналов аудита. Хранение 3 года удовлетворяет обоим минимумам, если они действуют для одних записей. Установи применимость каждого срока. Для метрик в этом примере указан собственный минимум 2 года.
