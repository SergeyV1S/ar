# Сброс пароля по электронной почте

| ID | Требование | Критерий приёмки |
|---|---|---|
| ФТ-01 | При запросе сброса пароля зарегистрированного пользователя система должна присылать ему письмо со ссылкой сброса. | Дано зарегистрированный пользователь. Когда он запрашивает сброс пароля, на его адрес приходит письмо со ссылкой сброса. |
| ФТ-02 | Система должна ограничивать срок действия ссылки сброса 24 часами. | По истечении 24 часов использовать ссылку для сброса нельзя. Начало отсчёта требует подтверждения. |
| ФТ-03 | Система должна принимать ссылку сброса только для одного успешного использования. | После успешного использования та же ссылка не позволяет повторно сбросить пароль. |
| НФТ-01 | Письмо со ссылкой должно поступать в течение 60 секунд после запроса сброса. | От запроса до поступления письма на почту проходит не более 60 секунд. |

Уточни точную границу срока, если приёмка проверяет момент истечения. Успешное срабатывание одноразовой ссылки и срок доставки письма проверяются независимо.
