# Совместимость с заданной версией браузера

| ID | Требование | Критерий приёмки |
|---|---|---|
| НФТ-01 | Пользовательский интерфейс NMS должен поддерживать Chrome начиная с версии 100. | В Chrome 100 и согласованном наборе последующих поддерживаемых версий обязательные пользовательские операции дают предусмотренные результаты. |

Для применения уточни поддерживаемые операции и матрицу проверяемых версий. В этой учебной матрице Firefox и Edge обязательны начиная с версии 100, а Safari опционален. В другом учебном фрагменте указан Safari 14+. Сохраняй версию и обязательность из применимого материала.
