# Противоречие в сроках хранения

Один учебный пункт задаёт бессрочное хранение данных, другой требует удаления через год. Если оба пункта действуют для одного набора данных при одинаковых условиях, одновременно выполнить их невозможно.

Уточнение в диалоге. «К каким данным относится каждый из двух пунктов? Какое правило действует, если они описывают один набор данных?»

После ответа проверь объект, срок, момент начала отсчёта и подтверждённое действие по истечении срока. До разрешения конфликта этот набор данных не получает готового критерия. Требования к остальным подтверждённым наборам можно продолжать формулировать.
