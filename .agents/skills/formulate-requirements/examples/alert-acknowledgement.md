# Подтверждение алерта с обязательным комментарием

**ФТ-01.** При попытке подтверждения активного CRITICAL-алерта инженером с правом подтверждения система должна присваивать алерту статус ACKNOWLEDGED при наличии комментария и сохранять прежний статус при пустом комментарии.

| Дано | Когда | Тогда |
|---|---|---|
| Активный CRITICAL-алерт. Инженер вошёл в систему и имеет право подтверждения. | Инженер подтверждает алерт с комментарием. | Статус изменяется на ACKNOWLEDGED. |
| Те же условия. | Инженер пытается подтвердить алерт с пустым комментарием. | Статус остаётся прежним. |

**ФТ-02.** При попытке подтверждения активного CRITICAL-алерта с пустым комментарием система должна сообщить инженеру, что комментарий обязателен. Критерий приёмки. При условиях второй строки таблицы инженер видит сообщение об обязательности комментария.

Для полного охвата UC-004 извлеки следующие наблюдаемые результаты, каждый со своим критерием:

| Условие или событие | Ожидаемый результат |
|---|---|
| Инженер с правом подтверждает алерт в состоянии ACTIVE или NEW | Система записывает в журнал имя инженера, время и комментарий. |
| Алерт успешно подтверждён | Система сбрасывает таймер эскалации. |
| Алерт успешно подтверждён | Система отправляет событие в систему нотификаций. |
| Алерт успешно подтверждён | Система показывает обновлённый статус и того, кто взял алерт в работу. |
| Алерт уже CLEARED или ACKNOWLEDGED другим инженером | Система сообщает, что алерт уже обработан, и оставляет его состояние прежним. |
| Соединение потеряно до завершения подтверждения | Система сообщает о неудачной попытке подтверждения и сохраняет прежний статус. |
| Сессия истекла | Система перенаправляет инженера на страницу входа. |
| У инженера отсутствует право на операцию | Система сообщает об отказе в доступе с кодом 403. |

Проверь правило, по которому один алерт подтверждает только один инженер. Для задержки задано до 2 секунд на шаги от изменения статуса через обновление журнала и отправку события до отображения результата. При подготовке отдельного НФТ уточни точные границы замера. Автоматическое создание тикета в ITSM в этом варианте использования вынесено на обсуждение.
