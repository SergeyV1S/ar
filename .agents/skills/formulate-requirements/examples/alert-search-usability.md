# Удобство поиска алерта

Фраза «Интерфейс должен быть удобным» конкретизирована через задачу поиска и число действий.

| ID | Требование | Критерий приёмки |
|---|---|---|
| НФТ-01 | Пользователь должен находить алерт по ID устройства не более чем за 3 клика. | Пользователь находит нужный алерт по ID устройства, совершив не более 3 кликов от согласованного начального экрана. |

Уточни роль пользователя, начальный экран, допустимый способ ввода ID и признак успешного поиска, если система показывает несколько алертов. Три клика — порог из учебного примера.

Для другой задачи пример задаёт освоение основных операций новым инженером за 2 часа без обучения. Такой критерий требует перечня операций и условия успешного выполнения. Пример отдельного показателя опроса — SUS не ниже 70. Для него нужны состав участников и методика опроса.
