# Автоматическое закрытие алерта после нормализации

| ID | Требование | Критерий приёмки |
|---|---|---|
| ФТ-01 | Для активного алерта MAJOR по загрузке CPU система должна установить статус CLEARED, если загрузка остаётся ниже 80% более 5 минут. | Дано активный алерт MAJOR по CPU. Когда загрузка остаётся ниже 80% дольше 5 минут, статус алерта становится CLEARED. |
| ФТ-02 | При таком закрытии система должна добавлять в историю алерта причину закрытия. | После автоматического закрытия история содержит запись о нормализации как причине закрытия. |
| ФТ-03 | При таком закрытии система должна уведомлять инженера о нормализации. | После автоматического закрытия инженер получает уведомление о нормализации. |

Проверь строгие границы. Значение ровно 80% или продолжительность ровно 5 минут ещё не удовлетворяют указанному условию закрытия.
