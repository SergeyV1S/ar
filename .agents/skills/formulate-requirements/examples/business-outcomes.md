# Бизнес-цели с измеримым результатом

| ID | Требование | Критерий достижения |
|---|---|---|
| БТ-01 | Сократить среднее время обнаружения сетевых инцидентов, чтобы уменьшить штрафы за нарушение SLA. | Среднее время обнаружения (MTTD) снижается с исходных 45 минут до не более 10 минут. |
| БТ-02 | Повысить конверсию регистрации в платный план. | За 6 месяцев конверсия растёт с исходных 2% до 5%. |
| БТ-03 | Снизить трудозатраты на инвентаризацию сетевых устройств. | Трудозатраты на инвентаризацию снижаются на 30% относительно базового уровня. |
| БТ-04 | Снизить количество обращений в поддержку. | Количество обращений снижается на 20% относительно базового уровня. |

Для БТ-01 уточни события начала и конца замера, охват инцидентов и период наблюдения. Для БТ-02 уточни начало шестимесячного периода, состав группы регистраций и правило отнесения к перешедшим на платный план. Эти параметры понадобятся, если без них значения можно посчитать по-разному.

Для БТ-03 автоматизация инвентаризации — предложенный способ снизить трудозатраты. Для БТ-04 таким способом служит самообслуживание. Для обеих целей уточни, какие операции или обращения учитываются и за какие сопоставимые периоды считается снижение.

Фраза об управлении виртуальными сетевыми функциями (VNF) через единый интерфейс описывает возможность продукта. Показатель «охвачено 100% типов VNF» проверяет охват этой возможности после определения набора типов. Для бизнес-требования уточни ожидаемый эффект для бизнеса.
