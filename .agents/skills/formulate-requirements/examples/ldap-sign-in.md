# Успешный вход через LDAP

| ID | Требование | Критерий приёмки |
|---|---|---|
| ФТ-01 | После успешной аутентификации через LDAP система должна открывать пользователю главный дашборд NMS. | Дано действующий незаблокированный аккаунт в LDAP. Когда пользователь запрашивает вход с правильным логином и паролем, открывается главный дашборд. |
| ФТ-02 | После успешной аутентификации система должна создавать пользовательскую сессию длительностью 8 часов. | После входа создана сессия с установленным сроком 8 часов. |
| ФТ-03 | Система должна записывать в журнал аудита событие успешного входа. | После входа журнал аудита содержит событие успешного входа. |

Проверь перенаправление, свойства сессии и запись аудита независимо. Для приёмки срока уточни момент начала и правила продления. Для входа с неудачными попытками используй отдельное подтверждённое правило. [Пример блокировки аккаунта](account-lockout.md).
