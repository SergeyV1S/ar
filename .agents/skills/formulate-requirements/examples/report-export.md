# Чек-лист экспорта отчёта

**ФТ-01.** Система должна формировать отчёт по доступности за выбранный пользователем диапазон в запрошенном формате из XLSX, PDF и CSV.

При выборе периода и одного из поддерживаемых форматов проверь результат:

- [ ] Отчёт относится к выбранному диапазону и получен в выбранном формате.
- [ ] В отчёте присутствуют имя устройства, IP-адрес, процент времени работы, количество инцидентов и MTTR.
- [ ] Имя файла содержит период отчёта и дату генерации, как в образце `report_2025-01_20250201.xlsx`.

Выбор произвольного диапазона, скачивание без перезагрузки страницы и сообщение об ошибке генерации дают самостоятельные наблюдаемые результаты. Для ошибки уточни достаточное содержание сообщения. Для генерации отчёта за месяц задан отдельный порог в 10 секунд. Уточни объём данных и условия замера перед оформлением критерия производительности.
