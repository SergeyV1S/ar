# Группировка алертов в инцидент

| ID | Требование | Критерий приёмки |
|---|---|---|
| ФТ-01 | Система должна объединять алерты одного устройства в один инцидент, когда они попадают в настроенное окно времени. Окно по умолчанию составляет 5 минут. | Дано окно по умолчанию. Когда два алерта одного устройства попадают в одно окно, они входят в один инцидент. |

Для граничной проверки уточни начало отсчёта, алгоритм формирования окна и включается ли момент ровно 5 минут. Сохрани принадлежность к одному устройству как условие правила.
