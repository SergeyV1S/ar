# Сопровождаемость

Для требования к сопровождению опиши вид изменения, например добавление нового вида уведомлений, и результат, по которому видно, что изменение завершено. Если ограничены время или трудозатраты, зафиксируй единицу и условия оценки. Уточни, какие работы входят в замер и ограничено ли календарное время или суммарное время работы.

Проверяй, что источник задаёт свойство сопровождаемого продукта или обязательное ограничение. Общие условия завершения любой задачи команды, например обязательное ревью, относятся к рабочему процессу.

Требования к проценту покрытия тестами, полноте документации API и сроку обновления зависимостей могут задаваться как отдельные инженерные условия. Если такое условие обязательно для приёмки продукта, уточни охватываемый код, API или зависимости и способ проверки. Для срока обновления также уточни событие начала отсчёта.
