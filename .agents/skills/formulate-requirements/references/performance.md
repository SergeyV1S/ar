# Производительность

- Назови конкретную операцию и метрику. Задержка измеряет время выполнения, пропускная способность измеряет количество операций за единицу времени. Число одновременных пользователей описывает нагрузку. Роль RPS определяется формулировкой, например заданная интенсивность для проверки задержки или минимальная пропускная способность.
- Для задержки укажи начало и конец измерения, единицу, порог и способ агрегирования, если они существенны. p95 означает, что не менее 95% наблюдений укладываются в соответствующее значение перцентиля. Среднее и перцентиль дают разные пределы.
- Зафиксируй заданные нагрузку, объём данных, среду, состояние системы, окно или сценарий проверки. Если существенное условие отсутствует, уточни его. Фраза «без деградации» требует измеримого определения допустимого изменения.
- Если требование содержит пороги для разных операций или метрик, оцени каждый порог отдельно и сохрани связь с операцией.

Для загрузки интерфейса важны условия старта и число одновременных пользователей. Для обработки входного события проверь, считается ли задержка от получения до завершения обработки. Для генерации алерта отсчёт может начинаться с момента срабатывания правила, если так установлено. Если нужно замерить результат под нагрузкой, укажи среду и профиль нагрузки, определённые для проекта.
