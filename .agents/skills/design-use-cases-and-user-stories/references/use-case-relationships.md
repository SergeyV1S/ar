# Граница системы и отношения Use Case

Основание в `wiegers_sa_reference.md` — §§ 7.1 и 11.1.

- Обозначь границу рассматриваемой системы. Помести варианты использования внутрь, а пользователей, организационные роли и взаимодействующие внешние системы снаружи. Соедини акторов с вариантами, в которых они участвуют.
- Для обязательного вызова другого Use Case используй `include`. Связь идёт от включающего варианта к включаемому. Проверь, что включение требуется в ходе выполнения. Уже выполненное условие при входе оформляй как предусловие, если повторный вызов не требуется.
- Для условного расширения базового Use Case используй `extend`. Связь идёт от расширяющего варианта к базовому. Зафиксируй условие и момент расширения там, где это нужно для однозначности.
- Сверь диаграмму с текстовыми спецификациями. Дай название, назначение и поясни обозначения, если они нужны для чтения. Используй Mermaid для компактной схемы, когда пользователь просит диаграмму или она помогает объяснить отношения.
