# Definition of Done

Основание в `wiegers_sa_reference.md` — §§ 5.4 и 10 (шаблон 1).

Критерии приёмки описывают ожидаемое поведение конкретной истории. Definition of Done (DoD) фиксирует командные условия завершения задач, например прохождение code review, проверку критериев и обновление согласованной документации.

Добавляй DoD, когда пользователь его запросил или передал действующее командное соглашение. Сохраняй критерии приёмки отдельным блоком. Если критерии завершения команды нужны для результата и их нет во входных материалах, уточни их в диалоге.
