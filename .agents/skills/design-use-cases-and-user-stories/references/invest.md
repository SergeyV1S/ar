# Проверка User Story по INVEST

Основание в `wiegers_sa_reference.md` — § 5.2.

| Критерий | Что проверить |
|---|---|
| Independent | Можно ли брать историю в работу и выпускать отдельно. Если есть реальная зависимость, укажи её |
| Negotiable | Можно ли обсуждать детали реализации, сохраняя цель и обязательные правила |
| Valuable | Понятна ли ценность для указанной роли |
| Estimable | Хватает ли команде сведений о границах, правилах и зависимостях для оценки |
| Small | Укладывается ли объём в рабочий цикл команды. Справочник приводит ориентир в 1–2 спринта |
| Testable | Есть ли однозначные и проверяемые критерии приёмки |

Если история слишком большая или соединяет независимые цели, выдели меньшие истории с отдельной ценностью. Если история описывает техническое изменение, выясни, какую ценность оно обеспечивает и подходит ли формат User Story. Если ценность, границы или критерии зависят от неизвестного правила, уточни его в диалоге.
