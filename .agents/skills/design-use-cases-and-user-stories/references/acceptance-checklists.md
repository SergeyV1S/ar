# Чек-лист критериев приёмки

Основание в `wiegers_sa_reference.md` — § 5.3 (формат 3), § 1.4.

Для небольшой истории сформулируй каждый пункт как отдельный результат, который можно проверить. По необходимости укажи допустимые параметры, форматы, состав данных, границы по времени, вид результата и реакцию на сбой.

Каждый пункт должен давать однозначный результат проверки. Если пункт содержит абстрактное качество, например «понятное сообщение», уточни наблюдаемое содержание, состояние или следующее доступное действие. Если действие и результат зависят от нескольких условий, вырази это сценарием или таблицей решений.
