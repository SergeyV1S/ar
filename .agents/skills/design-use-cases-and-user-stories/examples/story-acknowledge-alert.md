# Подтверждение алерта

Пример из `wiegers_sa_reference.md`, § 5.1, US-002 (строки 491–496).

```text
US-002: Подтверждение алерта
Как NOC-инженер,
Я хочу иметь возможность подтвердить (acknowledge) алерт и добавить
комментарий с описанием предпринятых действий,
Чтобы другие инженеры видели, что инцидент находится в работе,
и избегали дублирования усилий.
```

## Проверка по примеру

- Результат нужен и инженеру, и коллегам. Подтверждение и комментарий могут составлять одну историю, когда вместе обеспечивают эту цель.
- Сопоставь историю с UC-004 из § 7.1 и сценариями § 5.3. Проверь, для каких алертов комментарий обязателен, какие данные видят коллеги и как система ведёт себя при повторном подтверждении.
