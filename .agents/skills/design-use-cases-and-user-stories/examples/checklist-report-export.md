# Чек-лист критериев экспорта отчёта

Пример из `wiegers_sa_reference.md`, § 5.3, формат 3, US-010 (строки 678–687).

```text
US-010: Экспорт отчёта по доступности

Acceptance Criteria:
☐ Пользователь может выбрать временной диапазон (произвольный)
☐ Доступны форматы экспорта: XLSX, PDF, CSV
☐ Отчёт включает: имя устройства, IP, uptime%, количество инцидентов, MTTR
☐ Генерация отчёта за 1 месяц занимает ≤ 10 секунд
☐ При ошибке генерации пользователь получает понятное сообщение
☐ Имя файла включает период и дату генерации: report_2025-01_20250201.xlsx
☐ Отчёт доступен для скачивания без перезагрузки страницы
```

## Проверка по примеру

- По примеру проверь форматы, содержание файла, имя, доступность результата и исход при ошибке.
- Для стабильной проверки времени могут понадобиться согласованные условия измерения. Пункт про «понятное сообщение» уточни через наблюдаемое содержание или доступное действие.
- Сравни список форматов с US-003 из § 5.1, если материалы относятся к одной поставке.
