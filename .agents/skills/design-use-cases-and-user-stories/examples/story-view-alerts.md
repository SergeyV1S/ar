# Просмотр активных алертов

Пример из `wiegers_sa_reference.md`, § 5.1, US-001 (строки 484–489).

```text
US-001: Просмотр активных алертов
Как дежурный NOC-инженер,
Я хочу видеть все активные алерты на одном экране,
отсортированные по серьёзности,
Чтобы быстро определять приоритет реагирования без переключения
между несколькими системами.
```

## Проверка по примеру

- Роль и ценность названы явно. Сортировка здесь поддерживает приоритизацию реагирования.
- При подготовке критериев проверь, что означают «активный», порядок серьёзности и поведение при отсутствии алертов, если эти условия важны для проекта. Уточни неизвестные правила.
