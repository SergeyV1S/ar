# Definition of Done команды NMS

Пример из `wiegers_sa_reference.md`, § 5.4, пример команды NMS (строки 704–713).

```text
Definition of Done (Команда NMS-разработки):
☐ Требования задокументированы в Confluence (FR + AC)
☐ SRS-раздел обновлён
☐ RTM обновлён (требование связано с тест-кейсом)
☐ Код прошёл code review (минимум 2 reviewer)
☐ Unit-тесты написаны (coverage ≥ 80%)
☐ Integration-тесты пройдены
☐ Acceptance Criteria протестированы QA
☐ Документация для пользователя обновлена (если применимо)
☐ Задача задемонстрирована PO на review
```

## Проверка по примеру

- Обновление документов, проверка тестов и демонстрация относятся к завершению задачи по соглашению команды. Функциональный результат отдельной истории проверяется через её критерии приёмки.
- Число согласующих и порог покрытия относятся к этому примеру. Для другого проекта возьми значения из его командного соглашения.
