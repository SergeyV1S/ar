# Экспорт отчёта по доступности

Пример из `wiegers_sa_reference.md`, § 5.1, US-003 (строки 498–504).

```text
US-003: Экспорт отчёта по доступности
Как руководитель NOC,
В момент ежемесячной подготовки отчётности для клиентов,
Я хочу выгрузить отчёт о доступности сетевых устройств за
произвольный период в формате XLSX и PDF,
Чтобы предоставить клиентам документальное подтверждение SLA без
ручного сбора данных.
```

## Проверка по примеру

- Расширенная форма показывает ситуацию, задачу и ценность. Используй её, если контекст объясняет, когда возникает потребность.
- В этой истории названы XLSX и PDF, в чек-листе US-010 из § 5.3 предусмотрен ещё CSV. Это отдельные примеры. При объединении требований согласуй допустимые форматы и границы периода.
